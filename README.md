COMO O SITE FUNCIONA!

Leia este arquivo de texto para saber os principais funcionamentos do site. 

O site é dividido em 5 páginas de navegação, no qual duas delas se encontram na página inicial.

Loading Screen:
Ao clicar no link, a primeira coisa que o usuário verá, será a tela de Loading. Nela, há uma flor animada para representar que a página está carregando. Introduzindo de maneira divertida para a home page.

Home Page:
Nela, temos o banner inicial do nosso projeto, centralizado a logo do jogo e ao lado direto um dos Bosses apresentados no mesmo.
Ao descer a página, encontramos dois botões. Neles, o usuário pode abrir uma nova aba e explorar tanto o trailer do jogo quanto ser direcionado para a plataforma Steam.
Descendo mais, há o prólogo da trama do jogo, para interessar o usuário a explorar mais do web-site. 
Abaixo do texto, há novamente outros dois objetos clicavéis que direcionam tanto para a Steam quanto para o Youtube, dessa vez com a diferença da DEMO que estará disponível após uma parcela do jogo estar em desenvolvimento.
Após estes tópicos, o usuário poderá encontrar um formulário de contato que poderá se comunicar com a nossa equipe sobre qualquer dúvida e qualquer feedback a respeito do jogo ou do funcionamento do site. 
Rodapé abaixo, se encontra tanto as opções de navegação quanto as nossas redes sociais e os direitos reservados do site.

Sobre o jogo:
Nesta página, o usuário poderá ler mais sobre do que o jogo se trata para ficar por dentro da trama e do estilo visual do mesmo. 
Colocamos um container de uma imagem do jogo para representar o espaço que estára uma prévia do mesmo funcionando. 

Sobre Nós:
A página mostra todos aqueles que participaram do projeto e quais foram seus papéis dentro do jogo. Os textos ainda não estão definidos com certeza. 
Logo abaixo das informações dos integrantes, há um banner de promoção clicável que direciona o usuário para a plataforma Steam. 

Concept Art:
Ao clicar, o usuário pode saber um pouco mais das nossas inspirações para o projeto, podendo ser direcionado à página de cada jogo na Steam ao clicar nas imagens.
Ele poderá ver também a arte dos bosses e o que ele deve esperar dos inimigos do jogo. 
Abaixo, se encontra o mesmo banner promocional citado anteriormente.

Contato: 
Ao clicar nesta opção, o usuário é direcionado para a home page e a página desce automaticamente para o formulário de contato.


OBS: Todas as funcionalidades foram pensadas em deixar usuário o mais a vontade possível e evitar que o mesmo cometa error e tenha tudo que precisa no momento certo. 

ARTES:
Nossa equipe se esforçou bastante para fazer todas as artes vistas no Site. Nenhuma delas foi usada Inteligêcia Artificial. 
A estrutura do site foi pensada para que o usuário tenha uma experiêcia única visitando nossa página, com muitos artifícios visuais memoráveis. 

MÚSICA:
Ao acessar o site, pode-se notar uma pequena caixa de som ao canto da página. Nela, o usuário pode ativar a música ambiente do site e desativar quando quiser. 

DETALHES IMPORTANTES:

Tudo neste site foi bem corrigido. As imagens que ficam por cima do menu, são propositalmente colocadas dessa forma para causar uma impressão de objeto 3D. 
Todos os botões estão funcionando assim como o formulário de envio.
